# 티스토리 발행 방식

## Decisions

- 티스토리 글 발행은 공식 API가 아니라 사용자 계정으로 로그인해 에디터를 조작하는 브라우저 자동화로 한다.
- 티스토리 로그인과 발행의 성공 여부는 실제 티스토리 블로그에 글이 올라온 것으로만 판단한다. 모의 응답이나 화면 일부 확인으로 대신하지 않는다.
- 티스토리 계정 정보는 로그와 화면 출력에 남기지 않는다.

## Boundaries

- 어디서 자동화를 실행할지(로컬, 서버, 별도 실행 환경)는 이 결정이 정하지 않는다.
- 브라우저 자동화 도구의 선택은 이 결정이 정하지 않는다.

## Why

티스토리 Open API는 글 작성과 파일 첨부 기능이 2024년 2월에 종료되어 API로는 발행할 수 없다. 사용자가 이전에 GitHub Actions에서 로그인에 실패했던 경험이 있어, 로그인과 발행이 이 제품에서 가장 위험한 부분이다. 그래서 실제 계정으로 끝까지 확인한 결과만 근거로 삼는다.

## Reconsider when

- 티스토리가 글 작성을 지원하는 공식 API를 다시 제공할 때
- 브라우저 자동화가 로그인 보안 절차나 약관 때문에 반복해서 막힐 때

## Still-rejected alternatives

- 공식 Open API 사용 — 글 작성 기능이 종료되어 동작하지 않는다. 공식 API가 다시 제공되면 재검토한다.
- 다른 블로그 플랫폼으로 이전 — 제품의 대상이 티스토리 블로그 운영자이므로 약속하는 변화가 바뀐다. 티스토리 발행이 지속적으로 불가능해질 때 재검토한다.

## Evidence worth preserving

- [티스토리 Open API 종료 안내](https://tistory.github.io/document-tistory-apis/): 글 작성과 파일 첨부 기능이 2024년 2월까지 순차적으로 종료됨.
